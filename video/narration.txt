TokenScope is an inference planning studio for builders shipping language model features. Start in the model planner, where an editable pricing table drives cost, latency, and throughput comparisons across five tiers, with the cheapest and fastest options badged automatically. The memory fit panel calculates weight size and KV cache for your context length at each quantization, and shows the arithmetic line by line, so the number is never magic. The batch simulator is a deterministic queueing model. Move the arrival rate and batch size, and watch p fifty and p ninety five respond, with a full data table as the accessible alternative to the chart. Finally, the route builder lets you compose escalation rules, cheap model first, premium only past a confidence threshold, and replay them against a synthetic request log to see the savings. A seven step guided tour walks newcomers through every panel. No live API is called; the Nebius integration point is documented.
